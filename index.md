# Megatron Video

Megatron Video is a private desktop tool operated by Ivan Sikuten. It prepares short videos and publishes them on the operator's own YouTube channels using the YouTube Data API, and reads channel statistics using the YouTube Analytics API to plan future content.

The app is used only by its operator and is not offered to other users.
